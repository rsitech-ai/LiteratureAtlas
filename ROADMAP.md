# Roadmap

## Current objective

- Make the public source repository auditable and reproducible.
- Produce a sandboxed Apple Silicon macOS build for direct distribution.
- Complete Developer ID signing, notarization, Gatekeeper, and quarantine proof.

## Near term

- Approve production icon and brand provenance.
- Resolve historical-source and chain-of-title blockers.
- Enable private security and conduct reporting.
- Confirm governance and release authority.
- Perform acceptance testing on macOS 26 hardware.

## Under consideration

- Universal direct-download build.
- Embedded and audited Rust acceleration.
- A signed automatic-update mechanism.
- iPad distribution.

These are directions under consideration, not dates or commitments.
