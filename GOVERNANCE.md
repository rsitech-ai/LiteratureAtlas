# Governance

The project uses the following role model: contributor, reviewer, maintainer,
release manager, security responder, and conduct responder. Roles are scoped;
release, security, and conduct authority must be explicitly appointed.

Changes should be discussed through issues or pull requests, reviewed by someone
other than the author when possible, and decided by documented consensus.
Security and conduct matters stay private. Conflicted participants recuse from
the relevant decision.

RSI Tech currently operates the project as a single-maintainer open-source
project. Rafal Sikora, as copyright owner and release manager, has final
authority when consensus is not possible. Security and conduct appeals are sent
confidentially to `info@rsitech.ai`; the responder must recuse when personally
conflicted and appoint an uninvolved reviewer where one is available.

Maintainer appointments or removals require a public pull request updating
`MAINTAINERS.md`. Official releases require the release manager to verify the
exact source revision, signing identity, notarization record, checksums, SBOM,
and published assets.
