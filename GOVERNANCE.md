# Governance status

The project uses the following role model: contributor, reviewer, maintainer,
release manager, security responder, and conduct responder. Roles are scoped;
release, security, and conduct authority must be explicitly appointed.

Changes should be discussed through issues or pull requests, reviewed by someone
other than the author when possible, and decided by documented consensus.
Security and conduct matters stay private. Conflicted participants recuse from
the relevant decision.

The maintainer appointment/removal process, required approval counts,
tie-breaker, emergency authority, and appeal process are not yet owner-approved.
Until they are, this repository must not claim mature multi-maintainer
governance. Official releases require a separately identified release owner.
