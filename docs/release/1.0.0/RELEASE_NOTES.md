# LiteratureAtlas 1.0.0

LiteratureAtlas is a private, local-first research workspace that turns a PDF
and Markdown library into an explorable knowledge universe.

## Highlights

- Import research documents from a folder you choose.
- Explore papers, topics, relationships, and open questions in the Knowledge
  Universe.
- Ask questions across your corpus and inspect cited local evidence.
- Turn reading into insights and structured research projects.
- Review local analytics and export durable research artifacts.
- Keep selected source-folder access read-only and supported model work on
  device.

## Requirements

- Apple Silicon Mac running macOS 26.0 or later.
- Supported Apple Intelligence configuration with the on-device model
  available for model-backed features.

## Distribution

No official RSI Tech binary is published yet. The release candidate will be
Developer ID signed with the hardened runtime, Apple notarized, and published
as a stapled DMG with a SHA-256 checksum and SPDX SBOM only after every recorded
gate passes. Source is licensed under Apache-2.0; third-party components retain
their own licenses.
